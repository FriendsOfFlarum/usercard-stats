# Usercard Stats

A [Flarum](http://flarum.org) extension. Add stats to the usercard for your forum users.

## Installation

Install with composer:

```sh
composer require fof/usercard-stats:"*"
```

## Updating

```sh
composer update fof/usercard-stats
php flarum migrate
php flarum cache:clear
```
